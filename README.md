# Прогноз цены подержанного автомобиля

Домашняя работа по регрессии на объявлениях CarDekho. По характеристикам автомобиля модель оценивает цену в индийских рупиях. На 1 000 тестовых объявлениях итоговая Ridge дала **R² = 0,945**, **RMSE = 178 010 ₹** и **455 прогнозов в пределах ±10%** от фактической цены.

[Ноутбук с результатами](AI_HW1_Regression_with_inference_pro.ipynb) · [Обученный пайплайн](car_price.pickle) · [Код приложения](app.py) · [HTML-профиль train](reports/train_profile.html)

## Данные и признаки

В исходном train 6 999 строк, в test 1 000. В train обнаружено 985 полных дублей. По всем признакам, кроме цены, повторяются 1 159 записей сверх первого экземпляра. Для каждой комбинации оставлена первая строка, поэтому модель обучена на 5 840 машинах. Тест сохранён в исходном составе. Локальные копии CSV позволяют повторить расчёт без скачивания данных. [Исходные выборки курса](https://github.com/Murcha1990/MLDS_ML_2022/tree/432d64b8d232cf538dd7d1e4b0ef30cc0ac9c2d9/Hometasks/HT1)

Цена имеет длинный правый хвост. В исходном train медиана составляет 450 000 ₹, среднее 639 515 ₹, максимум 10 млн ₹. На очищенном train у мощности и крутящего момента корреляция Пирсона 0,84. Для цены и года корреляция Спирмена равна 0,71, а Пирсона 0,43. Это послужило основанием проверить нелинейную зависимость от возраста. В ноутбуке есть распределения train и test, матрица Φk для смешанных типов и сравнение цен по типу коробки.

Объём и мощность приведены к числам. Момент переведён в Н·м, из диапазона оборотов взята верхняя граница. Если единица момента неоднозначна, значение считается пропущенным. Для газа топливная эффективность дана в км/кг, для жидкого топлива в км/л. В регрессию вместе с числом входит вид топлива. Медианы, параметры масштаба и словарь категорий при подборе параметров обучались заново внутри каждого обучающего фолда. [Правила подготовки](car_features.py)

## Сравнение моделей

Параметры подбирались по среднему R² на 10 перемешанных фолдах train с seed 42. Состав итоговой модели выбран по тому же критерию. MSE в таблице измерена в **миллиардах ₹²**. Для L0 показан вариант с четырьмя весами. В ноутбуке сохранены обе метрики на train и test для каждого эксперимента, включая все исследованные значения λ.

| Модель | R² train | R² test | MSE test, млрд ₹² | В пределах ±10% на test |
|---|---:|---:|---:|---:|
| МНК, 8 числовых признаков | 0,604 | 0,601 | 229,63 | 24,7% |
| Lasso, α = 10 000 | 0,601 | 0,587 | 237,53 | 24,7% |
| ElasticNet, α = 1, доля L1 = 0,99 | 0,603 | 0,598 | 231,09 | 24,6% |
| L0, четыре признака | 0,602 | 0,597 | 231,67 | 25,0% |
| Ridge с маркой, трансмиссией и другими категориями | 0,774 | 0,784 | 124,19 | 30,9% |
| Ridge с семейством модели и комплектацией | 0,886 | 0,908 | 52,68 | 35,6% |
| Ridge с дополнительными числовыми признаками | 0,929 | 0,935 | 37,29 | 42,3% |
| **Та же Ridge на логарифме цены** | **0,944** | **0,945** | **31,69** | **45,5%** |

Наибольший отдельный прирост тестового R² дало добавление категориальных признаков к числовым с 0,601 до 0,784. Семейство модели и комплектация дали ещё 0,124. Сведения о сроке эксплуатации и двигателе добавили через квадрат возраста, квадрат мощности, произведение возраста и мощности, мощность на литр, логарифм пробега и число отсутствующих характеристик. После перехода к логарифму цены средний R² на фолдах вырос с 0,877 до **0,910**. Для всех четырёх Ridge выбрано α = 1. Прогноз возвращается в рупии экспонентой.

У числовой МНК наибольший стандартизованный вес у мощности. Одно стандартное отклонение соответствует примерно 306 тыс. ₹ при фиксированных остальных признаках. Стандартизация почти ничего не меняет в прогнозах МНК. Lasso занулила веса эффективности и объёма двигателя, но её тестовый R² снизился. Для числовых признаков основной выигрыш L0 оказался в сокращении модели с восьми до четырёх регрессоров при небольшом изменении качества.

## Бизнес-метрики и ограничения

Первая метрика считает долю машин с ошибкой до 10% включительно относительно реальной цены. Вторая усредняет относительную ошибку с двойным штрафом за занижение. Коэффициент 2 принят как условная стоимость ошибки для бизнеса. Итоговая Ridge лидирует по обеим метрикам. Её средний взвешенный штраф на тесте равен **21,7%**, у варианта без логарифмирования **36,1%**.

| Тестовый срез итоговой модели | Машин | R² | RMSE, ₹ | В пределах ±10% |
|---|---:|---:|---:|---:|
| Все объявления | 1 000 | 0,945 | 178 010 | 45,5% |
| Все исходные признаки встречались в train | 213 | 0,951 | 291 134 | 50,7% |
| Новое для train описание | 787 | 0,908 | 131 621 | 44,1% |

Высокий R² совместим с промахами по отдельным машинам. У 545 из 1 000 тестовых объявлений ошибка больше 10%. Для машин ценой от 1,5 млн ₹ в допуск попали лишь 18 из 60 прогнозов, средняя абсолютная ошибка в этом сегменте составила около 494 тыс. ₹. Объектов дорогого сегмента мало. Техническое состояние конкретного экземпляра и регион продажи в данных отсутствуют. Для рынка после 2020 года качество не проверялось.

## Приложение и оценка сервиса

Вручную можно оценить одно авто. Форма открывается с примером Maruti Swift Dzire VDI 2014 года и пробегом 145 500 км. При исходных характеристиках результат составляет **468 221 ₹**. Для партии машин есть вкладка «Прогноз» и «Файл CSV» с кнопкой скачивания образца. Нужны 12 колонок из образца, числовые технические характеристики могут быть пустыми. В выгрузке сохраняются исходные строки и добавляется `predicted_price_inr`.

- **Удобство.** Одиночный прогноз не требует подготовки файла, а готовый CSV-образец задаёт порядок работы для нескольких машин. Форма сообщает о пропущенных столбцах и ошибочных значениях года или пробега.
- **Графики.** Гистограмма с логарифмической шкалой цены показывает и массовый сегмент, и дорогой хвост. На графике по годам медиана дополнена центральными 50% цен и количеством наблюдений во всплывающей подсказке.
- **Что читать сложнее.** У Ridge 808 коэффициентов с учётом категорий. На диаграмме показаны 15 наибольших по модулю в выбранной группе, остальные доступны в таблице. Коррелирующие признаки делят вес, а коэффициент логарифмической модели нельзя непосредственно читать как прибавку в рупиях.
- **Следующая итерация.** Подсказки по комплектациям уменьшили бы ошибки свободного ввода. Для каждого прогноза стоило бы оценить диапазон неопределённости на отдельной калибровочной выборке и проверить его покрытие по ценовым сегментам.

### Запуск

Запустите приложение из корня репозитория в окружении **Python 3.12**.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для воспроизведения всех экспериментов установите дополнительные пакеты и выберите **Run All Cells**.

```bash
python -m pip install -r requirements-notebook.txt
python -m jupyterlab AI_HW1_Regression_with_inference_pro.ipynb
```

Ноутбук обновляет `reports/train_profile.html` и `car_price.pickle`. Сохранённый пайплайн принимает DataFrame с исходными признаками и включает обработку строк, медианы, масштабы, OHE, регрессию и обратное преобразование цены. Для загрузки модели модуль `car_features.py` должен быть доступен рядом с приложением.
